# 别猜了 · StopGuessing

**把脑子里那句反复想的话，拆成今天能做的一件事。**

写下你最近反复在想的那句推测——比如「他三天没回我，是不是不想理我了」——它告诉你：
哪些是**事实**、哪些是**你在猜**、还有 **5 种你可能没想到的可能**，最后给你一件**今天就能做的小事**，和一句可以直接发出去的话。

在线体验：<https://stop-guessing-rkdab43x6vp.qoder.zone>（不用注册，手机打开更好用）

## 它想解决什么

2026 年年轻人最普遍的内耗，不是「事情难」，而是**在脑子里反复推演，但一步都没动**。

而市面上几乎所有相关产品——AI 陪聊、心理分析、塔罗解读、认知扭曲检测——都在帮你**推演得更久**。

「别猜了」反着来：**不帮你分析，只帮你迈出那一步。**

## 四个核心设计

### 1. 一个永远点不动的按钮

「再分析一下」是**灰的、永久禁用**，鼠标悬停才浮出一行字：

> 分析不会让答案变清楚，只会让你更累。

旁边的「去做」按钮是它的 1.6 倍宽、实心品牌色。

**交互本身就是立场。** 这个按钮不承担任何功能，它承担的是态度。

### 2. 事实 / 猜测 双栏对照

大部分人在写下那句推测的时候，是把「观察到的」和「补出来的结论」混着说的。
这个产品做的第一件事，就是把两栏分开：

| 事实（能验证的） | 你猜的（没法验证的） |
|---|---|
| 他 3 天没回我消息 | 他不想理我 |
| 最后一条是我发的 | 他在跟别人聊得更开心 |

### 3. 你还可能没想到的 5 种可能

不是安慰，是**用信息对抗想象**。每条带一个类型标签（客观 / 关系 / 时间 / 性格 / 意外），保证五个方向互不重复。

### 4. 计数器：这件事你猜了几次

同一句话反复提交，它会记下来：

```
这件事，你已经猜了 4 次
行动 0 次
```

**把「内耗」这个抽象词变成可见的数字。** 只存本地，不上传服务器。

## 功能清单

- 3 步流程：写一句话 → 选关系与时长 → 出报告
- 报告五块：一句话点破 / 事实与猜测双栏 / 5 种其他可能 / 今日动作 / 2 个备选动作
- 4 种关系（恋人 / 朋友同学 / 家人 / 同事上级）× 4 种时长
- 一键复制那句「可以这样说」
- 计数器（`localStorage`，不上云）
- 三种降级兜底：断网 / 模型超时 / 服务未配置，都会退回内置示例而不是白屏
- 移动端优先，手机上单屏可操作

## 技术实现

**前端零构建、零框架、零依赖**——纯 HTML / CSS / 原生 JS。

**一个服务端函数**做四件事：校验输入 → 调模型 → 严格校验输出结构 → 失败重试一次，再失败就降级。

| 项 | 说明 |
|---|---|
| 运行时 | Deno / edge（不是 Node，只用 `fetch`） |
| 函数入口 | `POST /functions/v1/app` |
| 密钥 | Sites Secrets：`LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL` |
| 模型 | OpenAI 兼容接口（当前用 DeepSeek `deepseek-chat`） |
| 限流 | 同一来源 1 分钟 10 次 |
| 安全 | 前端不含任何密钥；用户输入一律 `textContent` 渲染；上游错误不透传 |

### 输出结构（模型必须严格返回）

```json
{
  "body": "一句话点破",
  "facts": ["能验证的"],
  "guesses": ["你补出来的结论"],
  "others": [{ "text": "别的可能", "kind": "客观|关系|时间|性格|意外" }],
  "action": { "title": "", "why": "", "say": "", "time": "" },
  "alternatives": [{ "title": "", "desc": "" }]
}
```

`others` 必须恰好 5 条，`alternatives` 恰好 2 条，任一字段不合格就重试，两次失败降级到示例。

## 本地运行

纯静态部分，随便起个静态服务器即可：

```bash
python -m http.server 8080 --directory web
# 打开 http://localhost:8080
```

此时报告会走**内置示例**（因为没有函数环境）。要跑通真实模型需要 Deno：

```bash
export LLM_API_KEY=你的key
export LLM_BASE_URL=https://api.deepseek.com/v1
export LLM_MODEL=deepseek-chat
deno run --allow-net --allow-env functions/index.ts
```

## 部署

在 Qoder 里用 Sites 能力发布：`web/` 作为静态产物，`functions/` 作为服务端函数，密钥走站点 Secrets。

> ⚠️ 两个容易踩的点：**新站点默认是私有的**，必须手动改成「任何人可访问」；**草稿预览不执行函数也读不到 Secrets**，接完模型必须发布才能测。

## 开发过程中踩过的坑

1. **站点默认私有** —— 自己点开正常，无痕窗口打开是登录页。
2. **预览不执行服务端函数** —— 冻结的静态包，函数要发布后才跑。
3. **模型不总返回严格 JSON** —— 会多字段、会把类型标签写成「关系型」、会在前后加说明文字。解法是宽容解析 + 收紧 prompt，两边一起改。
4. **前后端超时冲突** —— 都设 12 秒，前端先断、后端白跑。改成后端 12 / 前端 15。
5. **禁用按钮拿不到焦点** —— 手机上既没有 hover，disabled 又不能 focus，提示永远不显示。改成让容器响应点击。

## 边界声明

「别猜了」**不是心理咨询，也不做任何诊断**。它不分析对方动机、不预测关系走向、不提供操控或试探类建议。

它只做一件事：把你从脑子里拉回今天。

如果你最近持续睡不好、什么都提不起劲，请联系学校心理中心或拨打心理援助热线。
